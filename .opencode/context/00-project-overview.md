# Project Overview

This project is an HR / recruitment platform focused on
candidate ingestion, enrichment, search, and agent-driven workflows.

Primary goals:
- Unified candidate profile with versioned CV diffs
- Robust ingestion of legacy and unstructured documents
- Deterministic + semantic search over candidate data
- Agent-assisted HR workflows with human-in-the-loop
- Production-grade agent deployment

Primary users:
- Recruiters
- HR operators
- Internal automation agents
